# Лабораторная работа №6 — GitHub Actions

Репозиторий содержит пять workflow для изучения автоматизации CI/CD.

При отправке изменений в `main` запускаются приветствие, сбор системной информации, Bash-скрипт и матричная проверка Ubuntu/macOS/Windows. Workflow проверки Pull Request запускается при создании PR в `main`.
